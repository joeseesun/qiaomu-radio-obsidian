# 贡献 / Contributing

请描述问题、Obsidian 版本和复现步骤。修复使用 feature branch 和 Pull Request；运行 `npm ci`、`npm run check`，提交重新构建的 `main.js`。UI 修改附真实宿主截图和测试范围。不提交测试库数据、令牌或个人文件。

Open an issue with reproduction steps and your Obsidian version. Use a feature branch and PR, run `npm ci` and `npm run check`, and include the rebuilt `main.js`. UI changes need real host screenshots and explicit device coverage. Never commit vault data or secrets.
